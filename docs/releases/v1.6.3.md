# Daytile 1.6.3

Daytile is now available under GPLv3 or later. The APK includes the Daytile and Kotlin licence notices.

This release adds catalogue information and Obtainium update instructions. Planner features, task storage and reminder timing are unchanged.

Install `daytile-1.6.3.apk` over the existing app to retain your plans. `SHA256SUMS.txt` contains its download checksum.

The corresponding source and build files are in the [v1.6.3 source tag](https://github.com/Adiseny/daytile/tree/v1.6.3).

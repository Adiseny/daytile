# Daytile 1.3.3

A smaller release with one fix. The planner's interface and features are unchanged.

## Fix

- Tapping Reminders while notifications are blocked now closes the date sheet, so the message pointing to system settings can be read. It previously appeared underneath the sheet.

## Faster and lighter

- Timeline tiles no longer wait for a layout pass before they are composed.
- The date sheet opens with less main-thread work: its bell is drawn directly and the notification permission is requested through the platform.
- Tighter release rules remove unused library code. The APK is about 28 KB smaller.

Daytile remains offline, with no account, network access, analytics or logging.

Install `daytile-1.3.3.apk` over the existing app to retain your plans. `SHA256SUMS.txt` contains the download checksum.

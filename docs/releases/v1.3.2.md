# Daytile 1.3.2

Performance improvements and reliability fixes, with the same planner interface and features.

## Faster and lighter

- Replaced Room with Android's SQLite using the existing database file and schema, preserving saved plans.
- Removed Material 3 and an unused native graphics library while retaining the planner's controls and appearance.
- Reduced launch work, unnecessary tile recomposition, and repeated layout and drawing work.
- Improved indexed reminder and title-history queries, reused database statements, and reduced crowded-day layout allocations.
- Skipped redundant reminder work when reminders are disabled and unnecessary block-column calculations when tapping empty time.
- Updated baseline-profile rules automatically follow the app's current code.

## Fixes and interaction improvements

- Corrected reminder timing around daylight-saving and time-zone changes.
- Matched reminder accents to their timeline tiles.
- Made drag auto-scroll follow the visible timeline edges.
- Fixed taps lost just after a block was changed and brief jumps after moving a block on a newly selected day.
- Enforced the overlap limit when rounded end times meet older, unsnapped blocks.
- Improved spoken calendar dates and splash-screen colour consistency.

Daytile remains offline, with no account, network access, analytics or logging.

Install `daytile-1.3.2.apk` over the existing app to retain your plans. `SHA256SUMS.txt` contains the download checksum.

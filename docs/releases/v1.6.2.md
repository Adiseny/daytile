# Daytile 1.6.2

- Day and week tiles use black text in the light palette and white in the dark palette, with at least 4.5:1 contrast at every hour. Their shared solid fill keeps colours stable when blocks overlap.
- Week titles fit complete measured glyphs, including multilingual text, and ellipsise where needed. Growing a tile no longer hides its title at certain sizes.
- The held week resize edge marks the lower border without hiding text. Titles remain consistent during resizing, after release and when returning from the day; cancellation restores them.
- Reminder chimes now decode on Android 8. Their audio is unchanged; compatible FLAC headers add four bytes per file.
- Removed the obsolete luminance calculation, colour-switch helpers and four cached fields. Corrected the README reminder caption.

Task storage and reminder timing are unchanged. No dependencies or persistent data are added. The signed APK is 140,897 bytes, 252 bytes smaller than 1.6.1.

Verification: 77 unit tests and all 81 Android tests on both Android 8 and Android 17. Checks cover pixels, native gestures, saving, cancellation, accessibility, reminders and crowded histories. An isolated minified update preserves all 57,456 test tasks byte for byte. Privacy, lint and signature checks pass.

Install `daytile-1.6.2.apk` over the existing app to retain your plans. `SHA256SUMS.txt` contains its download checksum.

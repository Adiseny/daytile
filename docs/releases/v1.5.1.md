# Daytile 1.5.1

- Reduced temporary allocations when scrolling crowded days and placing tiles.
- Reused title layouts when only a tile's visual offset changes.
- Removed redundant sorting during resizing, duplicate gesture state and repeated title input reads.

The interface, features and stored task size are unchanged. Daytile remains offline, with no account, network access, analytics or logging.

Install `daytile-1.5.1.apk` over the existing app to retain your plans. `SHA256SUMS.txt` contains the download checksum.
